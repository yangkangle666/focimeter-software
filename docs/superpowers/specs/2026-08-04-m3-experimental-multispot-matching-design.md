# M3 实验多光斑跨图匹配设计

## 目标

M3 接入 M2 的 `m2.multispot.experimental.1` 输出，在标定图与测量图检测数量不一致时建立保守的一对一物理光线对应关系。匹配成功后，M3 才为重叠子集生成内部 `spot_id` 并调用现有 S/C/A 计算流程。

本设计明确禁止以下做法：

- 将单图局部 `detection_id` 改名为 `spot_id`；
- 按数组顺序或单次最近邻直接配对；
- 为凑足点数匹配缺点、伪点、粘连点或边缘不完整点；
- 在多个拓扑假设无法唯一判定时选择其中一个；
- 使用真实图片或商用焦度计工程读数宣称计量精度。

## 已知现场约束

- 参考图与测量图检测数量可能不同，已知工程场景约为 `43 -> 27`、`43 -> 39`。
- 镜片形变可能使边缘光斑移出画面，因此点数相等不是匹配前提。
- M2 的 `detection_id` 只在单个 JSON 内有效，不能表达跨图物理身份。
- 规则方形阵列可能产生 90 度旋转和整数孔距平移别名。
- 当前缺少真实像元尺寸、孔间距、光学距离和波长等完整标定参数。

## 模块边界

### 实验输入适配层

新增 M3 私有适配层，接受一对满足以下条件的文档：

- `schema_version == "m2.multispot.experimental.1"`；
- `module == "m2_image_recognition"`、`status == "ok"`；
- `experimental == true`、`metrology_validated == false`；
- 两份文档 `task_id` 一致，`image_type` 分别为 `calibration` 和 `measurement`；
- `coordinate_type == "image_pixel"`；
- `quality.is_usable == true`；
- 每个检测包含唯一的图内 `detection_id`、有限的 `x/y` 和 `[0, 1]` 内的 `confidence`。

适配层将检测转换为不含 `spot_id` 的 M3 私有观测对象。`detection_id` 只用于错误定位和诊断，绝不参与物理身份生成。实验成功输入中的 `quality_flags` 必须全部为空；任一点存在未知或不安全标记时，整对输入保守拒绝，不静默过滤后继续。自然移出画面且未被 M2 输出的点按部分重叠处理。M2 已返回错误的文档直接转换为统一 M3 错误，不进入匹配。

### 跨图匹配器

匹配器输入两组无物理身份的点，输出：

- 两图中的一对一重叠检测索引；
- 由标定图拓扑位置生成的内部 `spot_id`；
- 仿射变换、匹配残差、重叠数量和歧义诊断；
- 未匹配点及其拒绝原因。

匹配器不计算 S/C/A，也不修改原始 M2 文档。现有计算器只接收匹配器生成的、具有同一 `spot_id` 集合的标准化重叠子集。

## 匹配算法

### 1. 单图晶格恢复

对标定图和测量图分别执行：

1. 使用近邻距离的稳健中位数估计局部孔距；
2. 从短邻接向量中估计两条非共线晶格基向量；
3. 将点投影到候选基底并舍入为临时整数行列坐标；
4. 拒绝行列碰撞、基底病态或晶格重建残差超限的候选；
5. 保留多个可能的轴交换和符号方向，不在单图阶段猜测绝对方向。

所有距离门限以估计孔距归一化。门限属于 M3 校准模型的 `matching_limits`，不得散落硬编码在算法中。

### 2. 部分重叠假设

匹配器枚举两图晶格坐标之间的轴交换、符号方向和整数偏移。每个候选只使用两图行列坐标交集，因此允许点数不一致和边缘点消失。

候选必须满足：

- 一对一，不复用任一检测；
- 匹配数量不小于模型门限；
- 匹配数量相对较小输入集合的覆盖率不低于模型门限；
- 置信度乘积形成的权重为正且有限；
- 加权仿射拟合满秩、保持方向且数值条件良好；
- 双向投影残差和最大单点残差均不超限；
- 变换的旋转、尺度、剪切和整体平移满足校准模型先验。

### 3. 规则阵列别名控制

纯规则阵列在没有方向标记时，可能无法区分 90 度旋转或整数孔距平移。仅凭更小残差不能证明物理身份。

匹配器对全部合格候选排序，并比较最佳与次佳候选。只有最佳候选在匹配数量、覆盖率和归一化残差的组合评分上超过 `minimum_hypothesis_margin`，才允许成功。否则返回 `COORDINATE_SYSTEM_INVALID`，原因标记为 `AMBIGUOUS_LATTICE_IDENTITY`。

固定相机和光阑场景可通过校准模型提供“小于半个孔距的最大整体平移”和“远小于 90 度的最大旋转”等先验消除部分别名。若真实位移超过这些已批准先验，M3 必须拒绝，不能放宽门限猜测；需要硬件方向标记或其他非对称锚点后才能继续。

### 4. 内部身份生成

成功候选确定后，按标定图恢复的规范晶格坐标排序生成连续内部 `spot_id`。生成过程只依赖标定拓扑和已确认的匹配关系，不依赖任一输入的 `detection_id` 数值。

M3 生成两份仅包含重叠子集的标准化内存文档。相同内部 `spot_id` 在两份文档中指向匹配器确认的同一物理光线。原始 `detection_id` 只保存在匹配诊断映射中，便于追溯。

## 计算流程调整

M3 入口按 schema 分流：

```text
v1 spot_id 输入 -> 现有严格校验 -> 现有计算
实验 detection_id 输入 -> 实验适配 -> 跨图匹配 -> 标准化重叠子集 -> 现有计算
```

实验路径中的模型最小点数检查针对 `matched_spot_count`，不再针对两图原始点数相等。计算结果增加以下质量诊断：

- `calibration_detection_count`；
- `measurement_detection_count`；
- `matched_spot_count`；
- `unmatched_calibration_count`；
- `unmatched_measurement_count`；
- `matching_rmse_pixel`；
- `matching_max_residual_pixel`；
- `matching_hypothesis_margin`；
- `input_schema_version`。

实验路径继续标记 `software_verified` 或 `simulation_only`，不得输出 `metrology_validated`。

## 错误策略

以下情况统一停止计算：

- 文档结构、任务 ID、坐标系或图像类型不兼容；
- 任一输入被 M2 标记为不可用；
- 可用检测不足、晶格无法恢复或拓扑碰撞；
- 重叠匹配点不足或覆盖率不足；
- 仿射拟合退化、反射、条件数过大或残差超限；
- 保留检测含不安全质量标记；
- 最佳与次佳候选差距不足；
- 90 度或整数孔距身份别名无法排除；
- 变换超过校准模型允许的旋转、尺度、剪切或平移范围。

几何和身份不确定问题返回 `COORDINATE_SYSTEM_INVALID`。输入 schema 或模型配置错误返回 `CONFIG_INVALID`。错误详情提供稳定的 `reason`，但不返回猜测的配对结果。

## 配置和校准模型

匹配门限归入 M3 校准模型的 `matching_limits`，包括：

- 最小匹配点数和最小重叠覆盖率；
- 晶格重建残差上限；
- 匹配 RMSE 和最大残差上限；
- 最大条件数；
- 最大旋转、尺度变化、剪切和整体平移孔距比；
- 最小输入置信度；
- 最小候选唯一性差距。

模拟模型中的值只用于软件测试并标记 `simulation_only`。真实门限必须由硬件结构、真实 M2 输出和标准镜片验证后更新。

## 测试方案

### 固定的 M2 输出夹具

在 `modules/calibration_calculation/tests/fixtures/m2_experimental_94/` 保存当前 M2 命令生成并人工审核的 94 点实验输出：

```text
spots_calib_multispot.json
spots_meas_multispot.json
manifest.json
```

`manifest.json` 记录生成命令、来源提交、文件 SHA-256、预期检测数量和审核状态。日常 M3 测试直接读取固定 JSON，不在测试运行时重新编译或调用 M2，也不修改 M2 源码。

### 必测场景

1. 94 点正常路径能够唯一匹配并进入现有计算；
2. 两图 `detection_id` 独立重排后，物理配对和计算结果不变；
3. 断言内部 `spot_id` 不是通过复制或重命名 `detection_id` 得到；
4. 标定和测量检测数量不一致时允许部分重叠；
5. 模拟 `43 -> 27` 和 `43 -> 39` 的边缘缺失场景；
6. 额外伪点、缺点、低置信点、粘连标记和边缘标记不会被强行配对；
7. 精确对称阵列产生等价 90 度或整数孔距候选时拒绝；
8. 候选评分差距不足时拒绝；
9. 反射、退化、过大旋转、过大平移和残差超限时拒绝；
10. 原有 v1 `spot_id` 输入和现有 74 项 M3 回归测试继续通过。

## 文档声明

完成上述实现和固定 94 点端到端测试后，M3 文档可写：

> 支持 M2 实验多光斑输出，经 M3 保守跨图匹配并生成内部物理光线身份后计算。

同时必须保留：

> 当前结果只经过软件和模拟数据验证。真实硬件参数、标准镜片和独立计量验证数据未齐全，不代表计量精度已验证。

在固定 94 点输出和匹配实现完成前，PR 维持阻塞，不请求合并。
