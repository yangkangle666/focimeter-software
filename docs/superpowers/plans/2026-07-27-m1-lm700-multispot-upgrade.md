# M1 LM700 / Hartmann Multi-Spot Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade M1 from a fixed five-spot default to a portable LM700 / Hartmann multi-spot input workflow with explicit provenance, replaceable calibration, complete bundles, and a legacy compatibility path.

**Architecture:** Preserve the M1 `schema_version=1.0` result envelope. Add optional profile and calibration sections to configuration, validate the calibration in a focused module, let the service resolve every declared project-relative dependency, and let the Web layer package those dependencies without performing any M2/M3 work.

**Tech Stack:** Python 3.14 standard library, `unittest`, local `http.server`, native HTML/CSS/JavaScript, JSON, deterministic standard-library PNG generation, PowerShell verification.

- [ ] **Step 4: Implement deterministic PNG generation**

Write a standard-library generator using `struct` and `zlib`. It must render grayscale `640 x 480` PNGs with a circularly clipped dense grid. The measurement fixture applies a quadratic-position displacement, not one global translation:

```python
def displaced_point(x: float, y: float, cx: float, cy: float) -> tuple[float, float]:
    dx = x - cx
    dy = y - cy
    return x + 0.006 * dx + 0.003 * dy, y - 0.002 * dx + 0.004 * dy
```

Use fixed dimensions, fixed grid spacing, fixed Gaussian-like integer kernel, and no randomness so reruns produce byte-identical files. Run:

```powershell
python tools/generate_hartmann_fixtures.py
```

Expected: both PNG paths are created and the script reports their dimensions and spot count.
