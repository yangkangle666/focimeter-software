# 项目参考资料

本目录保存标准、论文、原始演示文稿和说明材料。

## 使用规则

- `JJG 580-2005 焦度计.pdf` 和 `GB 10810.1-2005` 用于理解标准和验收要求。
- `陈文婷 - 2020 - 基于计算机视觉的镜片屈光力.pdf` 只能参考项目原理和“为什么这么做”。
- 陈文婷文章中的计算过程和公式不得直接作为本项目算法实现依据。
- `reference_implementation/` 中的 C++ 工程是答辩依据和现有原型，不代表最终四模块目录结构。
- `instrument_operation/` 只记录两台仪器的大致操作流程和界面；因镜片身份及放置方向未确认，不得把两段视频的 A 值互相比较或作为算法真值。
- `ui_reference/` 是后续 M4 的视觉参考，不覆盖统一接口和安全状态要求。
