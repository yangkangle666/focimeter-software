# Instrument operation references

These files document the approximate operator workflow and display layout of
two instruments. They are reference material for later M4 workflow and UI
development only.

| File | Purpose |
| --- | --- |
| `commercial_focimeter_measurement.mp4` | Commercial focimeter reading and centering behavior |
| `existing_instrument_operation.mp4` | Existing instrument centering and live S/C/A display behavior |
| `existing_instrument_spot_ui.jpg` | Existing spot image, crosshair, and parameter-panel layout |

It is unknown whether the two videos show the same lens or preserve the same
lens orientation. Their axis readings must not be compared as validation data.
These files are not part of `real_lens_repeat_set_002` and must not be used as
S/C/A ground truth.
