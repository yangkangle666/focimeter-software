# M2 真实数据接收与验证要求

## 目的

本文件定义 M2 从 `software_verified` 进入真实设备验证所需的最低材料。缺少这些材料时可以继续软件联调，但不得标记为 `metrology_validated`。

## 必需图片

每个任务至少提供：

1. 一张标定图和一张测量图，二者来自同一相机、同一分辨率、同一裁剪方式和同一坐标方向。
2. 原始或无损文件，优先 `.tif` 或无损 `.png`；不得只提供截图、聊天压缩图或后期增强图。
3. 图片不得带人工画框、文字、坐标或 AI 生成内容。
4. 如果算法需要背景扣除，提供同一曝光条件下的背景图。
5. 最好提供连续多帧，以评估曝光稳定性、光斑抖动和质心重复性。

每组数据必须说明：标定/测量关系、采集时间、是否插入镜片、镜片编号以及文件是否经过处理。

## 相机与采集参数

- 相机和传感器型号；
- 分辨率、像元尺寸、位深、单色/彩色模式；
- 曝光时间、增益、黑电平和是否启用自动曝光；
- 原图坐标方向、是否镜像或旋转；
- 文件格式和相机 SDK 是否执行了归一化、去噪或伽马处理。

负责人给出的 `1280 x 1024`、`4.8 um`、8 bit 等数值只能作为模拟参数，真实设备确认前不能写成计量依据。

## 光源与光学参数

- 绿光的中心波长、带宽、功率或亮度稳定性；
- Hartmann 光阑的孔数、孔距、孔径和非对称身份标记；
- 光阑到成像面的有效距离；
- 光学放大倍率或经标准件求得的 `mm/pixel`；
- 允许的标定图与测量图相对旋转、缩放和位移范围。

仅凭图像分辨率不能计算真实距离。像素到毫米换算至少需要像元尺寸和光学倍率，或者经过标准件得到的标定比例。

## 标准镜片与真值

用于计量验证的数据需要提供标准镜片编号、S/C/A 标称值、允差、测量方向和参考仪器结果。M2 只验证光斑坐标和身份，S/C/A 由 M3 计算并使用标准镜片校准。

`spot_id` 真值不要求硬件组人工逐点填写，但硬件必须提供能够唯一确定物理光线身份的设计依据，例如非对称孔、稳定外观特征或姿态锚点。完全对称十字仅凭坐标存在 90 度身份别名。

## 图片验收清单

- JSON 可解析，路径均为项目相对路径；
- 标定图、测量图和配置文件存在且可读取；
- 两张图尺寸和坐标方向一致；
- 五个目标光斑在 ROI 内完整可见，没有裁边；
- 不存在明显饱和、欠曝、粘连或大面积杂散反光；
- 同一任务的图片与配置可以追溯到同一次采集；
- 数据来源明确标记为 real、synthetic 或 AI-generated。

## 从软件验证升级到计量验证

必须同时满足：

1. 多组成对真实图像通过 M2，且错误场景能被正确拒绝。
2. 光斑检测率、质心重复性和错配率达到负责人批准的指标。
3. `spot_id` 物理身份由非对称标记、稳定特征或硬件锚点验证。
4. M3 使用真实配置和标准镜片完成校准。
5. 结果经过负责人和硬件组复核。

在此之前，所有测试报告使用 `software_verified` 或 `synthetic_verified`，不得使用 `metrology_validated`。
